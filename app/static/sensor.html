Quick Start

Step 1: Create Your Site

Register your site with Harbour to get an ingest key:

curl -X POST https://agent-harbour.fly.dev/api/sites \
  -H "Content-Type: application/json" \
  -d '{"name":"My Documentation Site"}'

You'll receive a response with your site_id and ingest_key:

{
  "site_id": 1,
  "ingest_key": "abc123...",
  "warning": "Store this ingest key securely.",
  "dashboard_url": "https://agent-harbour.fly.dev/sites/1"
}
⚠️ Important: Save your ingest_key immediately. It cannot be retrieved later.

Step 2: Deploy the Worker

Option A: Using Cloudflare Dashboard (Easiest)

  1. Log in to Cloudflare Dashboard
  2. Go to Workers & Pages → Create application → Create Worker
  3. Name it (e.g., "agent-sensor") and click Deploy
  4. Click Edit code and paste the worker code from our repository
  5. Click Save and Deploy
  6. Go to Settings → Variables and add:
    • HARBOUR_URL = https://agent-harbour.fly.dev
    • HARBOUR_SITE_ID = 1 (your site ID)
    • HARBOUR_INGEST_KEY = your ingest key (as a secret)

Option B: Using Wrangler CLI

npm install -g wrangler
wrangler init agent-sensor
cd agent-sensor
# Copy cloudflare-worker.js to src/index.js
wrangler secret put HARBOUR_INGEST_KEY
wrangler deploy

See the full guide in our repository for detailed instructions.

Step 3: Add Worker Route

  1. In Cloudflare Dashboard, go to your website
  2. Navigate to Workers Routes
  3. Click Add route
  4. Pattern: *yourdomain.com/*
  5. Worker: Select your agent-sensor worker
  6. Save

All requests to your site will now pass through the sensor!

Step 4: View Your Dashboard

Access your site's sightings dashboard:

curl https://agent-harbour.fly.dev/sites/{your-site-id} \
  -H "Authorization: Bearer YOUR_INGEST_KEY"

Or get JSON data:

curl https://agent-harbour.fly.dev/api/sites/{site_id}/sightings \
  -H "Authorization: Bearer YOUR_INGEST_KEY"

What Gets Detected?

The sensor recognizes these AI crawlers out of the box:

  • OpenAI: GPTBot, ChatGPT-User, OAI-SearchBot
  • Anthropic: ClaudeBot, Claude-Web, Claude-User, Anthropic-AI
  • Google: Google-Extended, GoogleBot-AI, GeminiBot
  • Perplexity: PerplexityBot, Perplexity-User
  • Meta: Meta-ExternalAgent, FacebookBot, Meta-ExternalFetcher
  • ByteDance: Bytespider
  • Others: Amazonbot, CCBot (Common Crawl), Cohere-AI, Diffbot, YouBot, PetalBot, Applebot, Grok (xAI), DeepSeek

Unknown bots with bot/, crawler/, or spider/ patterns are labeled as UndeclaredBot.

Not tracked: Development tools like curl, wget, Postman, HTTPie, python-requests.

Privacy & Security

  • ✅ No IP addresses stored or transmitted
  • ✅ No raw User-Agent strings persisted
  • ✅ Query strings stripped from paths automatically
  • ✅ Ingest keys hashed on server (SHA-256)
  • ✅ Rate limiting to prevent abuse
  • ✅ Anonymous by default — only labels, no identifiable data
